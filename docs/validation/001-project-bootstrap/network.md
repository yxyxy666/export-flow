# 后端独立运行与网络边界

**日期**：2026-10-07  
**验证编号**：VC-004  
**追踪**：[`AC-059`](../../product/acceptance-criteria.md#ac-059)、[`SC-014`](../../product/acceptance-criteria.md#sc-014)；[任务](../../../specs/001-project-bootstrap/tasks.md)

开发页面和构建预览在没有后端配置、环境变量或业务连接适配器的情况下可使用。
后端仅注释占位，没有启动服务；没有为了验证而停止现有中间件，也未读取或修改其数据。

## 已有证据

- 逐项读取运行模块，并扫描 `fetch`、`XMLHttpRequest`、`EventSource`、`WebSocket` 和 `setInterval` 调用入口，没有发现业务调用；全部业务 API 与 Hook 文件是注释且未被导入。
- Vite 配置仅设置本机地址、固定端口与 React 插件，没有后端代理或中间件地址。
- 页面 DOM 只显示导航、文字标题或 404，没有可触发业务提交或下载的控件。
- 实际操作期间查看 warn/error 控制台，没有错误。开发模式 Vite 自身使用 HMR 连接，不等于业务 SSE。

## 覆盖缺口

IAB 工具没有请求列表接口，读取资源计时也报告不可用，未取得完整 Network 面板或抓包记录。
上述源码和运行证据支持静态骨架不依赖后端，但不能冒充实际网络面板检查。
VC-004 记为部分完成；由项目负责人评审，或在可用目标浏览器补看 Network 后闭合。
