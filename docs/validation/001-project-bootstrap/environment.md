## 待评审的覆盖缺口

1. 工具只提供 IAB，没有可用的 Chrome、Edge、Firefox 或 Safari 会话；IAB 的精确版本也未取得。不能宣称已验证 ADR 所要求的全部浏览器。
2. 浏览器工具没有 Network 请求记录接口；页面资源计时接口在其只读范围不可用。没有完整的网络面板证据，只完成源码、导入链、无连接配置运行及控制台核对。
3. 没有注入页面异常或移除 DOM 根节点；异常恢复出口与入口错误仅通过源码、类型检查核对。

恢复条件：在可用的目标浏览器记录真实版本并补查页面与 Network；必要时在手工调试环境触发异常出口。
本期 [`SC-014`](../../product/acceptance-criteria.md#sc-014) 的安装、类型、构建和静态页面部分有证据，版本记录部分尚不完整，**不判定整条通过**。
缺口须由项目负责人评审；收尾任务保持待验收，不把实施授权等同于验收批准。
