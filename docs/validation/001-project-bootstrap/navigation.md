# 静态导航实际验证

**日期**：2026-10-07  
**验证编号**：VC-001、VC-002、VC-005  
**追踪**：[`AC-029`](../../product/acceptance-criteria.md#ac-029)、[`AC-041`](../../product/acceptance-criteria.md#ac-041)、[`AC-057`](../../product/acceptance-criteria.md#ac-057)、[`SC-014`](../../product/acceptance-criteria.md#sc-014)；[任务](../../../specs/001-project-bootstrap/tasks.md)

使用 IAB 的页面点击、键盘、地址导航、刷新与历史接口查看实际页面；没有创建可执行测试文件。

| 操作 | 开发 5173 | 构建预览 4173 |
| --- | --- | --- |
| 进入 `/` | 替换跳转到 `/orders` | 替换跳转到 `/orders` |
| 菜单切换任务页 | URL、任务选中项、h1、文档标题一致 | 一致 |
| 两个业务路由直接访问及刷新 | 页面存在、标题正确 | 页面存在、标题正确 |
| 浏览器后退、前进 | 订单与任务路径及内容恢复一致 | 一致 |
| 键盘 ArrowUp 后 Enter | 焦点从任务项移到订单项，再激活订单路由 | 同样可用 |
| 未知路径 `/not-a-page` | 轻量 404、返回入口；两项均未选中 | 轻量 404、返回入口 |
| 固定路径大小写 | 路由使用显式大小写匹配 | `/Orders` 显示 404，返回入口可恢复 |
| 404 返回入口 | 点击返回订单管理 | Enter 激活链接返回订单管理 |
| 页面内容 | 仅对应中文名称，无业务控件 | 同样只有中文名称 |
| 控制台 | 检查时没有 warn/error | 检查时没有 warn/error |
