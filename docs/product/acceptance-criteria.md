# 验收与成功标准基线

**状态**：产品基线已确认；规格新增项待项目负责人整体审批
**日期**：2026-09-21

本文是项目所有验收标准（`AC`）和成功标准（`SC`）的唯一编号与定义来源。产品需求、功能规格、任务、测试和评审文档不得复制定义；引用具体编号时必须链接到本文对应锚点。

编号一经进入评审不得复用或改变原意。行为发生实质变化时新增编号，并把旧编号标记为“已取代”，不得静默改写。`AC` 描述可观察行为，`SC` 描述可度量结果或交付质量门槛；两者都必须在对应 `tasks.md` 中映射到测试或明确的替代验证。

- 产品基线：[`AC-001`](#ac-001) 至 [`AC-032`](#ac-032)、[`SC-001`](#sc-001) 至 [`SC-007`](#sc-007)；其中任务进度相关文字已按产品 `1.0.3` 的 SSE-only 决策同步。
- 待整体审批的规格新增项：[`AC-033`](#ac-033) 至 [`AC-044`](#ac-044)、[`SC-008`](#sc-008) 至 [`SC-013`](#sc-013)。原有两份功能规格已撤回；这些编号保留供后续评审和追踪，不表示已有规格或批准结果。重新编写的规格、计划和任务获得项目负责人明确批准前不得进入测试或实现。

## 订单查询与选择

<a id="ac-001"></a>
### AC-001 初始查询

给定用户进入订单管理页面，当页面加载完成时，那么页面展示筛选区、操作区、订单表格和分页区，并立即按无筛选条件查询第一页，分页默认每页 20 条。

<a id="ac-002"></a>
### AC-002 组合筛选

给定用户填写一个或多个筛选条件，当点击“查询”时，那么系统按照全部已填写条件的“并且”关系查询，并从第一页展示结果。

<a id="ac-003"></a>
### AC-003 重置

给定用户已经设置筛选条件或勾选订单，当点击“重置”时，那么系统清空筛选条件和已选订单，恢复第一页及每页 20 条，并立即按无筛选条件查询第一页。

<a id="ac-004"></a>
### AC-004 订单分页

给定查询结果超过一页，当用户切换页码或将每页数量设置为 20、50、100 时，那么系统展示对应页面的数据、当前页、每页数量和总条数；修改每页数量后返回第一页。

<a id="ac-005"></a>
### AC-005 范围校验

给定开始时间晚于结束时间，或最小金额大于最大金额，当用户发起查询时，那么系统阻止查询并给出可理解的校验提示。

<a id="ac-020"></a>
### AC-020 跨页选择生命周期

给定用户已经勾选订单，当切换分页时，那么系统保留已勾选订单；当用户修改筛选条件并重新查询时，那么系统清空此前勾选并展示新查询结果。

<a id="ac-021"></a>
### AC-021 订单号精确匹配

给定用户输入订单号，当执行查询时，那么系统仅返回订单号完全相等的订单。

<a id="ac-022"></a>
### AC-022 时间边界与时区

给定用户按 `Asia/Hong_Kong` 选择精确到秒的下单时间范围，当执行查询时，那么系统将开始和结束时间转换为 UTC，并包含恰好等于两个边界的订单。

<a id="ac-023"></a>
### AC-023 金额边界

给定用户输入最小金额和/或最大金额，当执行查询时，那么系统包含金额恰好等于已填写边界的订单。

<a id="ac-024"></a>
### AC-024 订单稳定排序

给定多条订单具有不同下单时间或相同下单时间，当展示查询结果时，那么系统按下单时间倒序、再按订单唯一 ID 倒序稳定排列。

<a id="ac-033"></a>
### AC-033 订单选择工具

给定订单列表有多页，当用户在不同页面勾选订单时，那么已选数量和订单集合跨页保留；点击“全选当前页”“反选当前页”或“清空已选”时，只按按钮语义更新选择集合。

<a id="ac-034"></a>
### AC-034 订单排序切换

给定订单表格已展示，当用户切换下单时间排序时，那么结果按升序或降序稳定排列，相同时间按订单 ID 同方向排序，并回到第一页。

<a id="ac-035"></a>
### AC-035 订单关键字搜索

给定用户输入关键字并查询，当关键字匹配订单号、客户姓名或手机号任一字段时展示该订单；匹配不区分英文大小写，并与其他筛选条件使用“并且”关系。

## 创建导出任务

<a id="ac-006"></a>
### AC-006 导出已选订单

给定用户至少勾选一笔订单，当点击“导出已选”、选择导出字段并确认时，那么系统基于已选订单和所选字段创建一个异步导出任务。

<a id="ac-007"></a>
### AC-007 无选择时禁用

给定用户没有勾选任何订单，那么“导出已选”不可用，并显示不可用原因。

<a id="ac-008"></a>
### AC-008 导出筛选结果

给定当前筛选结果不为空，当点击“导出筛选结果”、选择导出字段并确认时，那么系统基于符合当前筛选条件的全部订单和所选字段创建异步导出任务，导出范围不受当前页限制。

<a id="ac-009"></a>
### AC-009 空结果时禁用

给定当前筛选结果为空，那么“导出筛选结果”不可用，并显示不可用原因。

<a id="ac-010"></a>
### AC-010 创建幂等

给定系统收到多个携带同一 `Idempotency-Key` 的创建导出任务请求，那么这些请求只对应一个导出任务，不产生重复文件。

<a id="ac-011"></a>
### AC-011 大任务异步接受

给定导出范围包含十万条以上且不超过 200,000 条订单，当用户成功提交导出时，那么系统接受任务并允许用户通过导出任务列表查看后续状态，而不是等待文件在订单列表请求中直接返回。

<a id="ac-019"></a>
### AC-019 导出上限

给定导出范围超过 200,000 条订单，当用户尝试创建任务时，那么系统不创建任务，并提示当前数据量、单次上限以及缩小筛选范围或减少勾选数量。

<a id="ac-025"></a>
### AC-025 创建成功跳转

给定用户成功创建导出任务，当接口返回新任务时，那么系统清空已选订单并自动进入导出任务页面。

<a id="ac-030"></a>
### AC-030 创建失败保留状态

给定创建导出任务请求失败，当系统展示错误时，那么用户仍停留在订单管理页面，筛选条件、导出字段和已选订单保持不变。

## 查看与处理导出任务

<a id="ac-012"></a>
### AC-012 持续显示任务进度

给定任务处于等待中或生成中，当用户查看导出任务列表时，那么系统显示任务状态以及已处理条数、总条数和百分比，并持续更新进度。

<a id="ac-013"></a>
### AC-013 下载成功文件

给定任务已完成，当用户点击“下载”时，那么系统向用户提供对应的 Excel 文件。

<a id="ac-014"></a>
### AC-014 非成功任务禁止下载

给定任务处于等待中、生成中或失败状态，那么下载操作不可用，并显示不可用原因。

<a id="ac-015"></a>
### AC-015 成功任务元数据

给定任务已完成，当用户查看任务时，那么系统显示文件名、结束时间和文件大小。

<a id="ac-026"></a>
### AC-026 任务状态筛选

给定用户选择全部、等待中、生成中、已完成或失败状态，当执行任务筛选时，那么系统从第一页展示对应状态的任务；“全部”不附加状态条件。

<a id="ac-027"></a>
### AC-027 任务分页

给定导出任务超过一页，当用户切换页码或将每页数量设置为 20、50、100 时，那么系统展示对应页面、当前页、每页数量和总条数；默认每页 20 条，修改每页数量后返回第一页。

<a id="ac-028"></a>
### AC-028 任务稳定排序

给定导出任务列表正在展示，当列表首次加载或进度数据刷新时，那么任务按创建时间倒序、再按任务唯一 ID 倒序稳定排列。

<a id="ac-031"></a>
### AC-031 刷新保持当前页

给定用户正在查看非第一页任务，当普通进度数据刷新完成时，那么系统仍展示刷新后的当前页。

<a id="ac-036"></a>
### AC-036 活跃任务优先

**状态：待产品决策，不属于当前默认排序基线。** 本条与已确认的 [`AC-028`](#ac-028) 存在冲突；若批准本条，由本条取代旧默认排序标准，保留旧编号和定义，不得同时要求实现两种默认排序。

给定任务列表包含不同状态，当使用默认排序时，那么等待中和生成中的任务排在终态任务之前；生成中按进度降序排列；同组同进度按创建时间倒序、任务 ID 倒序稳定排列。

<a id="ac-037"></a>
### AC-037 进度排序

给定用户切换进度排序，当选择升序或降序时，那么任务按百分比排序，并以默认状态优先级、创建时间和任务 ID 作为稳定次序；操作后回到第一页。

<a id="ac-038"></a>
### AC-038 任务关键字搜索

给定用户输入关键字并查询，当关键字匹配任务编号或文件名时展示该任务，并与状态筛选使用“并且”关系。

<a id="ac-016"></a>
### AC-016 失败任务重试

给定任务失败，当用户执行重试时，那么系统按原任务的导出范围和字段配置创建一个具有新任务编号的任务，并保留原失败任务记录供后续查看；初始化后的订单数据只读，因此原筛选范围不会因数据变化而漂移。

<a id="ac-017"></a>
### AC-017 非失败任务禁止重试

给定任务处于等待中、生成中或已完成状态，那么重试操作不可用，并显示不可用原因。

<a id="ac-018"></a>
### AC-018 永久保留

给定任意时间创建的导出任务，当用户查看任务记录和已完成任务的文件时，那么记录与文件仍然保留，已完成任务仍可下载。

<a id="ac-032"></a>
### AC-032 重试后返回第一页

给定用户成功重试失败任务，当新任务创建完成时，那么系统返回导出任务列表第一页，并保留原失败任务记录。

## 按需 SSE 生命周期

<a id="ac-039"></a>
### AC-039 活跃时更新、终态后停止

给定任务页可见且存在 `PENDING` 或 `RUNNING` 任务，当进度通道启动时，那么进度持续更新且不回退；全部任务进入终态后通道关闭。mock 阶段验证相同生命周期，但不得声称真实 SSE 已完成。

<a id="ac-040"></a>
### AC-040 单例通道唤醒

给定当前没有活跃进度通道，当创建或重试产生新任务、页面重新可见或执行刷新发现活跃任务时，那么系统建立一个通道；同一时刻不得存在重复通道。

<a id="ac-042"></a>
### AC-042 服务端显式空闲标记

给定真实 SSE 通道中的任务均已进入终态，当后端经过空闲宽限期并再次确认没有活跃任务且活动版本未变化时，那么后端发送 `stream-idle` 标记并结束响应；前端收到属于当前通道且没有更新活动的标记后主动关闭 `EventSource`，不得因该次正常空闲关闭自动重连。

<a id="ac-043"></a>
### AC-043 创建与空闲判定竞态

给定创建或重试新任务与后端空闲判定并发发生，当两者无法证明严格先后或创建/重试提交使活动版本变化时，那么新任务优先，后端取消本次 `stream-idle`，经过宽限期后重新判断；不得用前后端墙上时间或相等时间戳决定顺序。

<a id="ac-044"></a>
### AC-044 空闲关闭后重新开启

给定 SSE 已因 `stream-idle` 正常关闭，当本客户端创建或重试成功、任务页首次进入或恢复可见、浏览器恢复联网、手动刷新，或同浏览器其他标签页通知新任务时，那么前端执行一次快照查询并在存在活跃任务时重新建立唯一 SSE 通道；异常断线按受控退避重连，不视为正常空闲关闭。系统不得注册固定或低频轮询。

## 导航

<a id="ac-029"></a>
### AC-029 无效地址

给定用户访问未匹配的前端路由，当页面加载完成时，那么系统显示轻量 404 结果和“返回订单管理”入口，不显示独立 403 或 500 页面。

<a id="ac-041"></a>
### AC-041 后台导航一致性

给定用户打开应用，当在左侧菜单切换页面时，那么 URL、选中菜单和页面标题一致；访问未知地址时展示轻量 404 和返回订单管理入口。

## 产品成功标准

<a id="sc-001"></a>
### SC-001 订单列表查询

在 110,000 条订单的数据量下，常用筛选接口 P95 不超过 500 ms（本地参考环境）。

<a id="sc-002"></a>
### SC-002 创建导出任务

接口 P95 不超过 500 ms；成功返回后不等待文件生成。

<a id="sc-003"></a>
### SC-003 导出能力

110,000 行、9 列的 Excel 在本地环境中 60 秒内生成；200,000 行在 120 秒内生成；生成的文件均可正常打开。

<a id="sc-004"></a>
### SC-004 服务稳定性

JVM 最大堆设置为 512 MB 时完成 110,000 行导出，不发生 OOM。

<a id="sc-005"></a>
### SC-005 任务可见性

成功任务进度最终达到 100%；失败任务保留失败时的实际进度并展示明确的错误摘要。

<a id="sc-006"></a>
### SC-006 幂等性

携带同一 `Idempotency-Key` 的重复请求只对应一个导出任务。

<a id="sc-007"></a>
### SC-007 数据准确性

导出行数与任务创建时命中的订单数量一致，表头及列顺序与用户选择的导出字段一致。

## 规格交付成功标准

<a id="sc-008"></a>
### SC-008 订单页面视觉质量

在 1280×720 下订单页面无控件遮挡，主要操作可达。

<a id="sc-009"></a>
### SC-009 订单页面质量门禁

订单管理规格范围的自动化测试、类型检查和生产构建全部通过。

<a id="sc-010"></a>
### SC-010 订单后端闭环

订单查询、任务创建、幂等、MySQL 事务 outbox 和 RabbitMQ 投递通过自动化集成测试；RabbitMQ 暂时不可用时，已提交任务和 outbox 不丢失，并在恢复后完成幂等投递。

<a id="sc-011"></a>
### SC-011 任务页面视觉质量

在 1280×720 下任务页面无控件遮挡，主要操作可达。

<a id="sc-012"></a>
### SC-012 任务页面质量门禁

导出任务管理规格范围的自动化测试、类型检查和生产构建全部通过。

<a id="sc-013"></a>
### SC-013 任务后端闭环

**状态：待取代的旧进度流验证草案，不作为新缓存方案的验收要求。** 技术方案完成 ADR 评审后须新增稳定编号描述新的验证目标，不得静默改写本条或同时要求两套进度机制。

RabbitMQ 消费与确认、任务状态推进、Excel 流式生成、文件发布、下载、失败重试、Redis 进度事件和 SSE 回补通过自动化集成测试；重复投递或消费者恢复不得生成重复文件或使终态回退。
