# ADR-0011：装配对账、选择性数据块重建与可信进度

2026-10-17增量：[ADR-0012](0012-user-resume-and-live-progress.md)将相同核验及选择修复扩展到用户继续前的未封存收集区间。

**日期**：2026-10-17　**状态**：已接受（2026-10-17随004规格0.3批准）；测试阶段与生产实施已获负责人明确批准，见004任务审批记录。

## 背景与冲突

负责人要求结束装配时核对文件和数据库登记，异常报错后自动重试；匹配部分复用、不匹配部分重建，按核验结果重算进度并显示黄色重建提示。见[004规格](../../specs/004-task-management/spec.md)与[修复契约](../../specs/004-task-management/contracts/assembly-repair.md)。

[ADR-0008](0008-worker-execution-lease-and-recovery.md)采用连续可信前缀和显示高水位；本期变更前坏块可能全量新代，装配错误没有自动局部修复能力。本决策在装配修复范围内接受任意匹配块复用和显示进度允许下降，取代旧ADR对应约束。其他fence、原消息责任、文件保护、POI工作文件不可续写等原则继续适用；暂停受[ADR-0010](0010-task-pause-control-barrier.md)约束。

## 决策

- 保留先收集后装配；入口全清单对账、装配逐块EOF校验、最终Excel校验，不新增SSE读盘或运行巡检。
- 新增不可变分段清单及封存摘要，为块登记缺失提供独立区间和内容基线；任意匹配数据块均保留，坏段用新blockId写入、事务CAS切换选择。不能续旧POI工作文件。
- 分段重读必须匹配原区间、数量和内容摘要，外部来源变化或恢复证据缺失明确失败；数据库未知HOLD，不猜测记录不存在。
- 同任务、原命令及当前执行身份内自动修复，持久每任务轮次预算，3轮；不重置原异常接管预算，不生成新执行命令，不自动继续PAUSED。
- `trusted_processed_count`为当前显示计数，修复对账提交时允许下降；原高水位仅作历史数据。版本单调，百分比不要求单调；HTTP、缓存和SSE同字段，前端接受高版本低计数。
- 修复计划、段选择、进度和通知事务一致；长文件I/O在事务外，提交重验完整身份及清单／修复版本。黄色提示由持久repairState驱动。
- 旧登记、替换历史及受保护文件不因修复删除；兼容迁移与存量实际校验补齐后才能启用。旧二进制不得忽略新清单回退执行。

## 替代方案与代价

仅保留连续前缀会重建仍匹配的后段，不符合需求。直接采信无登记文件或重查后混入变化源数据不能保证原导出集合。保留显示高水位会掩盖已失去的工作量，不符合重算要求。

分段清单和修复历史增加持久元数据与并发边界；不能保证数据库和文件恢复证据同时丢失仍可恢复。只读来源也不保证其数据不可变，需内容摘要校验并保留明确失败出口。

精确类型、轮次预算、迁移、函数和覆盖映射随[计划](../../specs/004-task-management/plan.md)、[模型](../../specs/004-task-management/data-model.md)及[任务审批表](../../specs/004-task-management/tasks.md#审批记录)共同获批。保留ADR-0008的历史记录，本决策作为对应范围的新决策关联旧ADR。实施测试与运行证据见[验证记录](../validation/004-task-management/verification.md)，性能与计时部分按本期排除清单保持未验证。
