# ADR-0012 用户继续与自动进度通知

状态：已接受；日期：2026-10-17；依据：负责人本次明确要求暂停后继续，并授权规格、测试先行后直接实施。规格见[005](../../specs/005-task-resume-and-live-progress/spec.md)。

扩展[暂停屏障](0010-task-pause-control-barrier.md)：只有用户显式、幂等、版本受控的继续事务可解除PAUSED封存。保持原任务和命令身份，原command重开READY，清旧投递token，重设本次投递窗口，历史attempt保留。重新认领已有execution递增fence，保留恢复预算；旧控制版本仍被所有写入口拒绝。

扩展[选择性修复](0011-selective-block-repair-and-progress.md)：恢复审计支持未封存连续登记区间，以断点前缀而非任务总量检查完整性；有独立基线的坏段选择性重建，无依据不能从磁盘制造可信记录。核验结果重算进度，POI工作文件重新生成。沿用持久3轮修复预算。

启用生产Spring定时调度使既有进度发布与暂停对账真实执行。验收增加真实自动SSE至最终采用100%的功能链路；不将已收集行数充当成功。无需新增中间件、轮询或全量重建。

回滚：先停止新增继续入口和请求受理，再回退程序；新增继续回执表保留，禁止删除暂停／进度／块记录。已继续任务按既有执行与暂停控制处理，不能靠回退数据库恢复封存。已有服务和文件根目录保持原配置。
