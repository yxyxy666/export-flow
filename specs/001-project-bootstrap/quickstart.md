## 前端命令（实施后）

从仓库根目录执行；Windows PowerShell 可直接使用以下形式。

```powershell
node --version
pnpm --version
```

首次初始化配置后，实施者执行安装并提交真实生成的锁文件：

```powershell
pnpm --dir frontend install
```

锁文件存在后的复现及检查使用：

```powershell
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend typecheck
pnpm --dir frontend build
```

启动开发页面：

```powershell
pnpm --dir frontend dev
```

建议地址为 `http://127.0.0.1:5173`。结束开发进程后或使用另一终端查看构建结果：

```powershell
pnpm --dir frontend preview
```

建议地址为 `http://127.0.0.1:4173`。端口占用时报告实际冲突，不结束不属于本轮的进程。
页面路由直接访问依赖开发或预览服务器的 SPA 回退；本期不设计生产服务器部署配置。

不提供 test 脚本，也不执行 Maven、Flyway 或 Java 启动命令；后端 POM/Java 文件本轮只是注释占位。
